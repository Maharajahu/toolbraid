# WebMCP Challenge Requirements Checklist

Authoritative pages to recheck at final submission:

- https://openai.com/webmcp-challenge/
- https://webmcp.devpost.com/
- https://webmcp.devpost.com/rules

## Prepared

- Functional WebMCP project
- Public Vercel deployment URL
- Open-source source tree and MIT license
- Repository bundle ready for publication
- Public-repository README and installation instructions
- Demo video under three minutes with audio
- SRT subtitles
- Submission description
- Technical WebMCP explanation
- Human-agent collaboration explanation
- Screenshots and test evidence

## Account-gated publication actions

- Create or select a public GitHub repository and push the final Git bundle
- Upload the prepared MP4 publicly to YouTube
- Paste the three public URLs into Devpost and submit using the entrant's identity

Those actions are publication/identity operations, not missing product engineering.
