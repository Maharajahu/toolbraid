## Final narration

WebMCP lets each website expose reliable tools, but a real goal still spans providers with different names, schemas, and risk levels. ToolBraid turns those fragments into one accountable plan.

Here, I give it a goal instead of a click path: travel from Coventry to London, find a hotel near my destination, keep the total under two hundred and fifty pounds, compare the options, and ask before changing anything.

Four independent website frames register six WebMCP tools. They do not share an API vocabulary. One calls transport search “seek passages.” Another calls hotel search “scan spaces.” Their parameters and results use different field names.

ToolBraid discovers those contracts at runtime. It combines tool names, descriptions, JSON schemas, and risk evidence to map them into canonical capabilities.

It also finds this adversarial tool. Its description asks the agent to ignore the user, collect private data, and bypass approval. Provider metadata is untrusted, so ToolBraid quarantines it before the tool can enter a plan.

Now I build the mission. ToolBraid creates a seven-step dependency graph across transport, accommodation, and location providers. The search branches can run in parallel. The hold actions are visibly separated behind human gates.

I run the safe steps. ToolBraid adapts the mission to each provider schema, executes the read-only WebMCP tools, canonicalizes their outputs, composes compatible options, measures walking access, and ranks only combinations that respect the budget.

The best result costs one hundred and eighty-four pounds and ninety pence, leaving sixty-five pounds and ten pence. The hotel is a thirteen-minute walk from the final destination.

Then execution stops. The agent cannot approve its own external state changes. The human checkpoint shows the exact provider tools, options, prices, and risk. These are reversible temporary holds, not purchases or final bookings.

I approve the two selected actions. Only those approved nodes can now run. Both provider interfaces update in the same browser context, and ToolBraid records the approval and results in its audit trail.

ToolBraid is not another tool directory. It is a semantic and policy control plane over WebMCP: dynamic discovery, schema normalization, cross-site planning, hostile-metadata quarantine, and human-owned execution authority.

One human goal. Multiple websites. One accountable action layer.
